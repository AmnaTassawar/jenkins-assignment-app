# Project Name
Automating CI/CD Pipeline using GitHub Actions and Docker

## Project Description
This project implements a Continuous Integration and Continuous Deployment (CI/CD) pipeline using GitHub Actions and Docker. Whenever code is pushed to the main branch, GitHub Actions automatically builds and tests the Docker image and publishes it to Docker Hub.

## Technologies Used
- GitHub
- GitHub Actions
- Docker
- Docker Hub

## How to Run the Application
1. Clone the repository.
2. Build the Docker image.
3. Run the Docker container.

## CI/CD Pipeline
1. Developer pushes code to GitHub.
2. GitHub Actions triggers automatically.
3. Docker image is built.
4. Build verification is performed.
5. Image is pushed to Docker Hub.

## Deployment
The latest Docker image is automatically published to Docker Hub.
